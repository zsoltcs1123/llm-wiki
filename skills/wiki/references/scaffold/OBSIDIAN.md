# Obsidian Usage

Open this wiki directory itself as the vault.

## Recommended Setup

- Start from [HOME.md](./HOME.md).
- Keep the file explorer on the left.
- Keep backlinks, outgoing links, and outline on the right.
- Use local graph from concept pages and hub pages.

## Recommended Core Plugins

- Backlinks
- Outgoing links
- Graph view
- Outline
- Page preview
- Quick switcher
- Search
- Bookmarks
- Workspaces

## Recommended Workspaces

- `Browse`: note in center, backlinks and outline on right
- `Graph`: note in center, local graph visible
- `Write`: note only, minimal sidebars

## Browsing Pattern

1. Start from [HOME.md](./HOME.md) or [wiki/index.md](./wiki/index.md).
2. Jump into a concept hub.
3. Use backlinks to find supporting source pages and neighboring concepts.
4. Use the local graph to see nearby clusters.
5. Open [wiki/log.md](./wiki/log.md) when you want to understand what recently changed.

## Working Rules

- Treat `wiki/` as the maintained knowledge layer.
- Treat `raw/` as input material, not the main browsing surface.
- Use relative markdown links.
- Do not add personal `.obsidian` noise unless a shared setting clearly improves the vault for future use.
